# 💰 SmartPense – Smart Expense Manager

### Take Control of Your Money. Spend Smarter. Save Better.

SmartPense is a simple, smart, and user-friendly expense management web application designed to help students and individuals track their daily expenses, manage budgets, understand spending habits, and achieve savings goals.

## 🚀 Features

- 💸 **Expense Tracking** – Add, edit, and manage daily expenses.
- 📊 **Expense Analytics** – Understand your spending habits through visual insights.
- 🧠 **Smart Spending Insights** – Get insights into your spending patterns.
- 🎯 **Savings Goals** – Set financial goals and monitor your progress.
- 🤖 **Money Buddy** – Get helpful money-management suggestions.
- 📅 **Transaction History** – View and manage previous transactions.
- 📱 **Responsive Design** – Access the application on different screen sizes.

## 🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and interactivity
- Chart.js – Expense visualization (if integrated)

## ⚙️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start tracking your expenses!

## 🎯 Project Objective

The main objective of SmartPense is to encourage better financial habits by providing an easy way to record expenses, monitor spending, and plan savings.
